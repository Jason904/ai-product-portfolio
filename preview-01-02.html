01 / THE PROBLEM CONTROL COUPLING

ONE CHANGE. FULL REROLL.

当结果已经基本正确，为什么修改一个变量，仍然会重新打开整张画面的不确定性？

TEST CASE COMPARATOR / 随滚动自动切换评测维度
SOURCE STANDARD / 基准对照组 CURRENT VALID STATE
LOCKED VARIABLES CHARACTER · RELATION · COMPOSITION
EDIT TARGET POSE (前伸手势 → 强控制姿态)
INTENT SPEC

全景基线锁定 · 仅针对红衣控制者动作发起单变量变更。

TEST 01 / CHARACTER DRIFT POSE ✓ · CHARACTER ✗
身份特征重算 ✗
INTENT RESULT POSE ✓ (动作抬高手势已生效)
UNWANTED DRIFT CHARACTER ✗ (面部、发型与身份被重绘)
FORENSIC VERDICT

动作改动触发特征重绘，缺乏角色显式控制，导致红衣人面孔与身份严重漂移。

TEST 02 / RELATION DRIFT POSE ✓ · RELATION ✗
站位拓扑拉散 ✗
INTENT RESULT POSE ✓ (动作抬高手势已生效)
UNWANTED DRIFT RELATION ✗ (三人站位拓扑被拉散重排)
FORENSIC VERDICT

单人动作重构未锁定空间拓扑，三人站位间距被重新解算，空间拓扑关系崩塌。

TEST 03 / COMPOSITION DRIFT POSE ✓ · COMPOSITION ✗
镜头视角与景别漂移 ✗
INTENT RESULT POSE ✓ (动作抬高手势已生效)
UNWANTED DRIFT COMPOSITION ✗ (机位与景别重构)
FORENSIC VERDICT

动作修改触发整幅画面重新采样，原本满意的全景构图被重构为近景俯仰，镜头视角失真。

01 / 核心判断 · PRODUCT JUDGMENT

改变一个变量，不应该重新打开所有变量。

用户预期：只改动作 → 生成现实：角色、站位、构图全被推翻重算

问题不是模型画不好，而是所有变量混在了一起——只要没有显式拆开控制，任何局部微调都会沦为全图重新抽卡。

CORE PRINCIPLE // 核心法则

只改想改的，保留已经确认的内容

CHANGE WHAT MATTERS. KEEP WHAT ALREADY WORKS.
