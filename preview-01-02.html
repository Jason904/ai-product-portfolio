ROOT CAUSE FORENSIC DISSECTION // 三大深层机理解剖台

为什么单变量修改，会引发全局连锁反应？

● 根因透视 // CAUSAL CHAIN
01 / 用户表达层 EXPRESSION ENTANGLEMENT
↳ 根源锁定：对应「01 身份特征重算」

多种要求写在同一段文字里，缺少分别控制的依据

一段文字需要同时表达角色长相、动作、站位和镜头。创作者很难只保留满意的部分，往往需要一边修改，一边反复协调其他要求。

文字混合描述 ➔ 控制无法分离
02 / 模型生成层 GLOBAL RESAMPLING
↳ 根源锁定：对应「02 站位拓扑拉散」

模型根据当前条件重新生成，无法自动锁定已有内容

模型会根据当前描述重新生成整张画面。即使用文字写上“其他保持不变”，模型也只能尝试理解这一要求，无法自动保证原本成立的部分不发生变化。

全局重新采样 ➔ 已有成果被洗牌
03 / 工作流返工层 COMPOUNDING REWORK
↳ 根源锁定：对应「03 机位景别重构」

局部修改带来全图返工，陷入反复调试深渊

每次尝试都可能解决一个问题，又引发新的变化。为了把一个动作调对，创作者需要重新检查和微调整张画面。

单变量试错 ➔ 连锁连环返工
PRODUCT JUDGMENT // 核心判断

改动作时，已有的角色、站位和镜头应该能继续用。

问题不是模型画不好，而是所有变量混在了一起——只要没有把控制显式拆开，任何局部微调都会沦为全图重新抽卡。

01 / 核心判断 · PRODUCT JUDGMENT

改变一个变量，不应该重新打开所有变量。

用户预期：只改动作 → 生成现实：角色、站位、构图全被推翻重算

问题不是模型画不好，而是所有变量混在了一起——只要没有显式拆开控制，任何局部微调都会沦为全图重新抽卡。

CORE PRINCIPLE // 核心法则
