## 本地查看

直接双击 `index.html` 即可。

## GitHub Pages 部署

1. 进入 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main`
4. Folder 选择 `/(root)`
5. 保存

发布地址通常为：

`https://Jason904.github.io/ai-product-portfolio/`
